# Vectnor app icons

The canonical `vectnor.svg` and `vectnor-small.svg` are the supplied `App-Icon-Dark.svg`: a teal-to-green V on a navy rounded tile. The light and monochrome variants live in `assets/brand/`.

Original AI-assisted artwork supplied by the project contributor on 2026-10-12, licensed MIT OR Apache-2.0. See `LICENSE.txt` and `ASSETS.md`.

Run `packaging/icons.sh` with resvg available to regenerate PNGs, Windows ICO, macOS ICNS and Linux hicolor icons. macOS adds the standard transparent margin around the tile. The runtime app bar uses the light or dark variant for its theme.
